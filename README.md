# SkyFlight v1.2.2

Run `启动飞行模拟器.bat`

**S/W** nose up/down · **A/D** bank left/right · **Shift/Ctrl** throttle ·
**Z** full · **F** flaps · **B** brake · **C** camera · **F11** fullscreen ·
**R** restart · **H** help · **Esc** quit

Take off: **Z**, reach 100 km/h, hold **S**.
Land: **Ctrl** to 20%, **F**, tap **S**, **B**.
Top compass = heading.
