# SkyFlight v1.5.0

Run `启动飞行模拟器.bat`

**S/W** nose up/down · **A/D** bank left/right · **Shift/Ctrl** throttle ·
**Z** full · **F** flaps · **B** brake · **G** gear · **V** aircraft ·
**L** language · **C** camera · **F11** fullscreen · **R** restart ·
**H** help · **Esc** quit

Aircraft: prop trainer, light jet, twin jet.
Scenery: forests, villages, wind farms, lakes, rocks.
**L** switches the interface between Chinese and English.
