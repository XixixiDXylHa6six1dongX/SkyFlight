# SkyFlight v1.3.0

Run `启动飞行模拟器.bat`

**S/W** nose up/down · **A/D** bank left/right · **Shift/Ctrl** throttle ·
**Z** full · **F** flaps · **B** brake/airbrake · **C** camera ·
**F11** fullscreen · **R** restart · **H** help · **Esc** quit

Take off: **Z**, reach 100 km/h, hold **S**.
Slow down: hold **B**.
Top compass = heading.
